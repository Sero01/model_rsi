## Learnings
- MIT's first prompt names repetition as an in-scope failure, and its work guide says cut-off answers often repeat. It also gives the architecture. The plan's "goal only" prompt is a harder test than Astra had.
- One pass is a batch of up to 512 generations or 1,024 teacher-forced texts. p50c used 32 generation passes and 18 teacher-forced passes, 9,632 generations in total, across 158 turns and 20.3 wall-clock hours, 4.7 of them an outage.
- MIT's forward-pass server is not published. Only `harness/sandbox.py` (bubblewrap), the Codex config and the instructions file are.
- MIT forbade running the model in the kernel, so the plan's CPU forward-pass question is settled: forbid it.
- Reported 50-pass success is one run. Other runs of the same experiment scored far lower or submitted nothing.
- MATH-500, computed from MIT's per-problem data: base 7.90 (clustered SE 0.97), edited 48.10 (SE 1.90), paired delta 40.20 (SE 1.72).
